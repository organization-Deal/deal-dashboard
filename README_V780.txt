v7.80 — Manual Expense Payment Flow UI

อัปต่อจาก v7.79.2:
- apply-v780-manual-expense-payment-flow-ui.mjs
- package.json

Flow ใหม่:
1) บันทึกรอจ่าย
   -> สถานะในตาราง = รอจ่าย
   -> มีปุ่ม "โอนแล้ว"
   -> เมื่อโอน: เลือกบัญชี + แนบสลิป -> เปลี่ยนเป็น จ่ายแล้ว

2) บันทึกว่าจ่ายแล้ว
   -> ระบบสร้างรายการเป็นรอจ่ายก่อน
   -> อัปสลิป + ยืนยันการจ่าย
   -> สำเร็จแล้วจึงเปลี่ยนเป็น จ่ายแล้ว
   -> ถ้าอัปสลิปล้มเหลว รายการไม่หาย แต่คงเป็น รอจ่าย

แก้อาการค้าง:
- POST มี timeout
- ไม่รอ refresh ตารางก่อนปลดปุ่ม
- Optimistic UI แสดงรายการทันที
